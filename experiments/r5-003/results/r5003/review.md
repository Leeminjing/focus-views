# 实现收尾复核

使用 implement/code-review 的 Standards 与 Spec 两条审阅路径，审阅者只读代码/已有材料，没有代替本机执行原生实验。

- Spec 复核发现初版查询流在没有新命令时未排空，空闲仍可填满环；已在空闲和等待输入消费期间持续 flush。巨型 Channel 测试对象移到堆，防止无关默认栈溢出遮蔽 FIFO/背压测试。最终 native codec 及真实 GUI 空闲超过旧配额的对照已执行。
- Standards 复核发现依赖安装可能留下半份配置；改为先备份并验证 helper、DLL、reuse，再执行安装，任一步失败均恢复全部原件并核对哈希，保留主错误。真实 DLL 锁阻止第二次复制，已经发生的首次 helper 复制也被回滚，未发布部分配置。
- 存储边界还增加了最小 data 长度、完整 cookie 槽、PE 头及显式 PID/创建时间编码，避免无符号长度下溢、部分槽及结构体 padding。对应反例纳入原生 codec。

实际执行结果以 summary/statistics/regressions 和原始归档为准。两次正式失败未改写；不把代码审阅、拒绝被准确检测或诊断完成等同于恢复成功。没有新增公共 SDK、任意应用兼容、崩溃恢复或系统重启保证。
