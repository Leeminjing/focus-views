## 状态规则

- **待研究**：尚无可复现证据。
- **部分支持**：仅在报告列明的资源子集、应用和条件下通过；必须列出遗漏和拒绝条件。
- **已验证**：声明范围内的正例、隔离性和必要失败路径均有可复现证据。
- **不支持**：某个明确条件已有失败证据或被明确排除；保留原因和报告引用。

每项结果应分别说明采集、恢复和独立分叉的结论。能观察不等于能恢复，能恢复不等于能隔离。未识别资源不能默认归为可共享。

## 证据记录格式

每次实验创建单独报告并从表格链接。报告至少包含：

1. 实验编号、日期、对应 CAP/FV 编号、待检验假设。
2. 系统 build、架构、SDK/编译器、提交或源码版本、权限和驱动条件。
3. 目标程序、资源清单、安全点和边界外依赖。
4. 运行命令、步骤、预期断言及判定规则。
5. 原始记录、内部状态观测、资源关系、文件版本与画面证据的位置。
6. 实际结果、反例、拒绝路径和清理结果；未运行的项目写“未运行”。
7. 分别给出保存、恢复、隔离的结论，明确适用边界和仍未知的问题。

一次失败不等于整个目标不可行；一次成功也不等于支持所有 Windows 应用。能力状态只跟随实验证据变化。
