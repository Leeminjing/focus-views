# 行为规格

状态：目标已确定，实现待研究。本文定义验收行为，不表示这些能力已经实现。

## 领域对象

| 对象 | 含义 |
| --- | --- |
| `View` | 运行时管理的独立运行环境，包含进程及其受管资源、图形与输入状态 |
| `Snapshot` | 在声明的资源边界和一致性条件下保存的固定运行起点及恢复所需关系 |
| `Action` | 针对某个 View 的操作及其投递、执行或失败记录 |
| `Frame` | 某个 View 实际产生的画面，带来源和采集时序信息 |
| `Artifact` | 从某个 View 导出的固定版本成果，带来源和版本信息 |

Snapshot 不等同于 Frame；Action 的提交成功不自动代表应用已经完成操作。具体调用协议待实验后确定。

## 平台与责任

首个平台为 Windows 11 x64，使用 C++20 和 Windows SDK。先以用户态机制开展实验；驱动不是禁止项，也不是预设答案。不为接口或预览引入 Windows App SDK、Electron 或其他应用框架。

运行时负责隔离、观察、输入、检查点、分叉、恢复、记录和成果导出。它不负责 Agent 推理、任务规划、任务轮次调度、成果取舍或自动状态合并。不依赖 Focus 模块，不将 Context、Patrol、Round 引入领域模型。

首阶段从应用启动时建立管理边界，不要求接管任意已运行的程序。远端服务、物理设备和整个宿主系统不属于被分叉的对象。

## 行为与不变量

| 编号 | 情况 | 必须满足的行为 |
| --- | --- | --- |
| FV-01 | 运行中的 View 保存 S0 | S0 固定；之后源 View 的变化不修改 S0 |
| FV-02 | 从 S0 派生 A、B | 从相同现场继续执行，包括已验证支持范围内的未保存状态 |
| FV-03 | 同时操作 A、B | 输入、交互状态及可变资源独立，真实桌面输入不被抢占 |
| FV-04 | 读取 A 的 Frame | 返回 A 实际产生的画面；预览关闭不影响 A 执行和画面更新 |
| FV-05 | 保留 A、B 终态 | SA、SB、Action 记录和 Artifact 持续可用，不回滚到 S0 |
| FV-06 | 再从 S0 派生 C | C 从原始现场继续，不继承 A、B 的后续变化 |
| FV-07 | C 使用 A、B 的成果 | 读取固定版本或导入私有副本；C 的修改不反向影响 A、B |
| FV-08 | 发现不能可靠恢复的资源 | 明确失败或报告不支持，指出具体资源和原因；不静默冷启动或共享可变状态 |
| FV-09 | 保存与恢复 | 分别证明保存一致性和恢复续接；句柄、引用关系与资源语义一起处理 |

“保留终态”与“各分支可以继续运行”都须验证。保存期限、跨管理进程重启、跨宿主重启、跨系统版本恢复尚未确定，不应提前承诺。实验必须声明生命周期边界，不能把仅保留活进程称为已证明恢复。

## 资源边界

每次 Snapshot 都应能说明包含哪些资源、使用什么一致性条件、依赖哪些边界外资源，以及哪些行为尚不支持。边界外资源不会随 Snapshot 回滚或复制。

| 资源性质 | 分叉规则 |
| --- | --- |
| 可安全共享的不可变资源 | 共享，并说明不可变条件及依赖 |
| 可复制的可变资源 | 建立分支私有状态 |
| 需重新建立的资源 | 重建并恢复相关引用关系 |
| 不能正确恢复或尚未分类的资源 | 阻止此次分叉并报告原因 |

对边界外的连接或设备，若无法证明重建、断开或继续使用符合声明语义，应拒绝分叉。不得把未复制的远端或设备状态当作恢复完成。

## 失败语义

- 失败报告必须包含操作阶段、涉及的资源、原因，以及源 View 是否可以继续运行。
- 保存未完成时不得发布为可恢复的 Snapshot；恢复未完成时不得发布为可操作的 View。
- 分叉失败时清理未发布分支的资源，保留原 Snapshot 和其他已存在分支。
- 发现隔离被破坏时明确报告，不能以正常成功结果掩盖共享或污染。
- 不支持项进入能力清单；诊断采集成功不能被计为恢复成功。

## 验收关口

| 关口 | 核心证据 | 关联行为 |
| --- | --- | --- |
| R1 | 未落盘内存恢复，执行从约定检查点续接 | FV-02、FV-09 |
| R2 | A、B 的内存、文件及受测资源独立，S0 固定 | FV-01、FV-02、FV-08、FV-09 |
| R3 | 并行交互、真实画面更新、宿主输入不被抢占 | FV-03、FV-04、FV-08 |
| R4 | 保留 A/B，从 S0 派生 C，并独立使用固定成果 | FV-05、FV-06、FV-07、FV-08 |

关口通过仅覆盖报告中的应用、资源、系统配置及检查点条件，不推导为通用 Windows 应用兼容性。具体实验见 [实验与关口](experiments.md)。
